
# Flashcard App (Static Deck)

A simple, interactive flashcard application built with HTML5, CSS3, and JavaScript.

## Features

- 10 question-and-answer flashcards
- Smooth CSS 3D flip animation
- Previous and Next navigation
- Progress bar and current card indicator
- Shuffle cards functionality
- Keyboard navigation using arrow keys
- Responsive layout for mobile and desktop

## Technologies Used

- HTML5
- CSS3
- JavaScript

## How to Use

1. Open the flashcard application.
2. Click the card to reveal the answer.
3. Use Previous and Next to navigate the deck.
4. Check the progress indicator.
5. Click Shuffle to randomize the cards.
